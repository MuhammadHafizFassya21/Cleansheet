# Product Requirements Document — CleanSheet AI

## 1. Product Summary
CleanSheet AI is a web application that helps users check, understand, and improve the quality of CSV data.

## 2. Problem Statement
Non-technical users often work with CSV or spreadsheet data that contains hidden issues. These issues can affect reports, dashboards, research analysis, marketing campaigns, and operational decisions.

## 3. Goals
- Help users detect data quality issues quickly.
- Provide a clear Data Quality Score.
- Explain problems in simple language.
- Recommend safe cleaning actions.
- Allow users to download cleaned data.

## 4. Non-Goals
- Not a full spreadsheet editor.
- Not a data warehouse.
- Not an advanced BI tool.
- Not a replacement for Excel.
- Not storing user data permanently in MVP.

## 5. Target Users
- Students and researchers
- MSMEs
- School admins
- Operations teams

- System detects at least 6 types of data quality issues.
- User can understand the biggest problem from the dashboard.
- User can download a cleaned CSV.
